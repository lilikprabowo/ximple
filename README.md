## Installation

- Install XAMPP on your local machine with min PHP Version 5.6.40
- Import databases on your local machine
- you can configure your mysql configuration on application/config/database.php for database name, username, password

### Clone

- Clone this repo to your local machine using `https://gitlab.com/fajaruddin93/ximple.git`

### Tech

This project uses Codeigniter 3. Make sure you have basic PHP Programming skills.
